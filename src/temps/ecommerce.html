Site E-commerce Dynamique

Objectif : Mettre en pratique la programmation Web avec Golang à travers la création d'un site e-commerce complet.

Technologies

  • Golang (Serveur HTTP, Gestion des routes)
  • HTML Templates (Actions, Boucles, Conditions)
  • CSS (Mise en forme responsive)

Challenges Techniques

Challenge 1 : Catalogue

Affichage dynamique d'une liste d'articles (minimum 5) stockés dans une variable globale. Chaque article inclut image, nom, prix et réduction optionnelle.

Challenge 2 : Détails Produit

Page dédiée affichant les informations détaillées (description, stock, etc.) avec gestion des erreurs si l'article est introuvable.

Challenge 3 : Administration

Formulaire d'ajout de produit avec validation des données et redirection automatique vers la page du nouveau produit.
