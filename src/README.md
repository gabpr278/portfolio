# Portfolio Personnel

Ce projet est un site web personnel de type CV/Portfolio, réalisé entièrement avec HTML, CSS et JavaScript, sans frameworks externes.

## Fonctionnalités

### Interface & Design
- **Design Moderne & Responsive** : S'adapte à tous les écrans (mobile, tablette, desktop).
- **Mode Sombre / Clair** : Bascule de thème avec persistance du choix (localStorage).
- **Animations** : Effets d'apparition au défilement (fade-in).

### Projets
- **Carrousel** : Défilement horizontal des projets.
- **Filtrage** : Tri des projets par catégorie (Web, Design, etc.).

### Contact & Interaction
- **Formulaire de Contact** : Validation en temps réel (champs requis, format email) et simulation d'envoi.
- **Compteur de Visites** : Incrémentation à chaque chargement de page (localStorage).

## Installation

Aucune installation complexe n'est requise.

1. Téléchargez ou clonez le projet.
2. Ouvrez le fichier `index.html` dans votre navigateur web préféré.

## Structure du Projet

- `index.html` : Structure de la page.
- `style.css` : Styles et mise en page.
- `script.js` : Logique interactive (thème, carrousel, validation, etc.).
- `PROGRESS.md` : Journal des prompts utilisés pour la génération du code.

## Technologies Utilisées

- HTML5
- CSS3 (Variables, Flexbox, Grid)
- JavaScript (ES6+)
